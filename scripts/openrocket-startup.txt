# Files in OpenRocket's jar that the design page reads while OpenRocket starts and opens a design, in
# the order it first reads them. scripts/slim-openrocket-jar.py writes these first, so start-up reads
# one stretch at the start of the jar (about 7 MB) instead of 128 KB blocks spread over 20 MB, and
# the page downloads that stretch in parallel as it opens (web/public/sw.js). Files not listed still
# load, as before; an outdated list only makes start-up slower.
# Made with scripts/startup-order.py (see there) from OpenRocket 24.12 opening a new rocket, "Two stage
# high power rocket" and "Pods--powered with recovery deployment".
